ASSIGNMENT 3 - RSA PERFORMANCE ANALYSIS

1. AIM
------
To study RSA public-key cryptography and compare key generation, encryption and
decryption time for different RSA key sizes and message sizes.

2. DEFINITIONS
--------------
Cryptography:
The science of protecting information using mathematical techniques.

RSA:
An asymmetric cryptographic algorithm. It uses a public key and a private key.

Public key:
The key that can be shared. In RSA it is used for encryption or signature verification,
depending on the operation.

Private key:
The secret key. In RSA it is used for decryption or signing, depending on the operation.

Plaintext:
The original readable message.

Ciphertext:
The encrypted form of the message.

Padding:
A structured method applied before RSA encryption or signing. Padding is required for
secure use of RSA.

OAEP:
Optimal Asymmetric Encryption Padding. It is a padding scheme used with RSA encryption.

SHA-256:
A cryptographic hash function that produces a 256-bit digest.

Performance analysis:
Measuring how long an operation takes and comparing the results.

3. MATHEMATICAL FORMULAS
------------------------

RSA key generation:

Choose two large prime numbers p and q.

    n = p * q

Euler's totient:

    phi(n) = (p - 1) * (q - 1)

Choose public exponent e such that:

    1 < e < phi(n)
    gcd(e, phi(n)) = 1

Calculate private exponent d:

    d * e = 1 mod phi(n)

Equivalently:

    d = e^(-1) mod phi(n)

Public key:

    (e, n)

Private key:

    (d, n)

RSA encryption (textbook mathematical form):

    C = M^e mod n

RSA decryption:

    M = C^d mod n

Here:
    M = message represented as an integer
    C = ciphertext represented as an integer
    e = public exponent
    d = private exponent
    n = RSA modulus

The supplied program uses RSA-OAEP with SHA-256. Therefore the actual library operation
includes OAEP encoding and is not simply raw textbook RSA.

OAEP maximum message length:

    mLen <= k - 2*hLen - 2

Where:
    mLen = maximum message length in bytes
    k    = RSA modulus length in bytes
    hLen = hash output length in bytes

For SHA-256:

    hLen = 32 bytes

In the program:

    max_len = key_size // 8 - 2 * 32 - 2

Why key_size // 8?
Because 8 bits = 1 byte.

5. CODE EXPLANATION
-------------------

key_sizes = [1024, 2048, 3072, 4096]
A Python list containing RSA key sizes in bits.

message_sizes = [128, 256, 512, 1024]
A list containing the required message sizes in bits.

iterations = 10
Each experiment is repeated 10 times to obtain an average.

for key_size in key_sizes:
    Repeats the experiment for every RSA key size.

key_times = []
Creates an empty list to store key-generation times.

start = time.perf_counter()
Records a high-resolution start time.

private_key = RSA.generate(key_size)
Generates the RSA private key.

public_key = private_key.publickey()
Extracts the corresponding public key.

end = time.perf_counter()
Records the end time.

key_times.append(end - start)
Stores the elapsed time.

statistics.mean(key_times)
Calculates the average key-generation time.

secrets.token_bytes((msg_size + 7) // 8)
Generates random bytes for the requested message bit length.
(msg_size + 7) // 8 rounds the number of bits up to a whole number of bytes.

PKCS1_OAEP.new(public_key, hashAlgo=SHA256)
Creates an OAEP encryptor using the public key and SHA-256.

encryptor.encrypt(message)
Encrypts the message.

PKCS1_OAEP.new(private_key, hashAlgo=SHA256)
Creates an OAEP decryptor using the private key.

decryptor.decrypt(ciphertext)
Decrypts the ciphertext.

assert decrypted == message

7. EXPECTED OBSERVATION
----------------------
Larger RSA keys generally require more time for key generation and private-key operations.
RSA encryption/decryption can only process messages within the OAEP size limit.
RSA is not normally used to encrypt large files directly; hybrid encryption is preferred.

8. VIVA QUESTIONS
-----------------
Q: What is RSA?
A: An asymmetric cryptographic algorithm using public and private keys.

Q: What is the purpose of the public key?
A: In this program it encrypts the message.

Q: What is the purpose of the private key?
A: It decrypts the message.

Q: Why is OAEP used?
A: It provides secure randomized padding for RSA encryption.

Q: Why is SHA-256 used?
A: It is the hash function used by OAEP in this program.

Q: Why is time.perf_counter() used?
A: To measure operation time accurately.

Q: Why is assert used?
A: To check that decryption recovered the original message.

Q: Why can RSA not encrypt arbitrarily large data?
A: RSA has a strict maximum message size determined by the modulus and padding.

Q: What is the difference between 1024-bit and 2048-bit RSA?
A: The modulus sizes differ; 2048-bit RSA provides substantially stronger security than
1024-bit RSA. 1024-bit RSA is obsolete for modern security.

COMMON CRYPTOGRAPHY DEFINITIONS
============================================================

Symmetric cryptography:
Uses the same secret key for encryption and decryption.

Asymmetric cryptography:
Uses a related public key and private key.

Encryption:
Transforms readable data into ciphertext using an algorithm and key.

Decryption:
Recovers plaintext from ciphertext using the appropriate key.

Hashing:
Maps input data to a fixed-length digest.

Digital signature:
A value generated with a private key and checked with the public key.

Key exchange:
A process through which parties establish a shared secret.

Confidentiality:
Only authorized parties can read the information.

Integrity:
Unauthorized changes to data can be detected.

Authentication:
Verifies the identity or origin of a communication.

Non-repudiation:
Provides evidence of origin or signing, subject to secure key control and identity binding.

Plaintext:
Original readable information.

Ciphertext:
Encrypted information.

Nonce:
A value used once with a cryptographic key.

Salt:
Random data added to a password before password hashing.

Padding:
Extra structured data added to fit or secure a cryptographic operation.

Modulus:
The number by which a value is reduced in modular arithmetic.

Digest:
The output of a hash function.
