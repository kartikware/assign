ASSIGNMENT 4 - CUSTOM ENCRYPTION AND DECRYPTION USING XOR
             AND BIT ROTATION
============================================================

1. AIM
------
To implement a simple custom encryption and decryption method using XOR, a generated
key stream and byte rotation.

2. DEFINITIONS
--------------
XOR:
Exclusive OR. A bitwise operation that outputs 1 when the two input bits differ.

Bit rotation:
A circular shift in which bits shifted out from one side are brought back on the other side.

Byte:
A group of 8 bits.

Key stream:
A sequence of key-derived values used to combine with plaintext bytes.

Plaintext:
Original readable input.

Ciphertext:
Encrypted output.

UTF-8:
A character encoding that converts text into bytes.

Hexadecimal:
A base-16 representation using digits 0-9 and letters A-F.

3. MATHEMATICAL FORMULAS
------------------------

XOR encryption:

    X = P XOR K

XOR decryption:

    P = X XOR K

This works because:

    (P XOR K) XOR K = P

Key stream in the supplied program:

    key_bytes = UTF8(key)

    k_i = key_bytes[i mod L]

    dynamic_key_i = (k_i + 17*i) mod 256

Where:
    i = byte position
    L = number of bytes in the key
    k_i = selected key byte

Rotation amount:

    shift = (i mod 7) + 1

Therefore shift values range from 1 to 7.

8-bit left rotation:

    ROL(x,s) = ((x << s) OR (x >> (8-s))) AND 255

8-bit right rotation:

    ROR(x,s) = ((x >> s) OR (x << (8-s))) AND 255

Encryption per byte:

    x = plaintext_byte XOR dynamic_key
    encrypted_byte = ROL(x, shift)

Decryption per byte:

    x = ROR(encrypted_byte, shift)
    plaintext_byte = x XOR dynamic_key

The mask 255 is used because:

    255 decimal = 11111111 binary

It keeps only the lowest 8 bits.

6. IMPORTANT LIMITATION
-----------------------
This is a custom educational cipher, not a standard, professionally reviewed encryption
algorithm. It should not be used to protect real confidential information. XOR and
rotations alone do not provide modern authenticated encryption.

7. VIVA QUESTIONS
-----------------
Q: What is XOR?
A: A bitwise operation that gives 1 when input bits differ.

Q: Why can XOR be reversed?
A: Applying the same key a second time restores the original value.

Q: What is bit rotation?
A: Circular movement of bits within a fixed-width value.

Q: Why is 255 used?
A: It is an 8-bit mask that retains only the lowest 8 bits.

Q: What is UTF-8?
A: A character encoding used to convert text into bytes.

Q: What does enumerate() do?
A: It returns the index and value of each item during iteration.

Q: Why is bytearray used?
A: It allows bytes to be appended and modified.

COMMON CRYPTOGRAPHY DEFINITIONS
============================================================

Symmetric cryptography:
Uses the same secret key for encryption and decryption.

Asymmetric cryptography:
Uses a related public key and private key.

Encryption:
Transforms readable data into ciphertext using an algorithm and key.

Decryption:
Recovers plaintext from ciphertext using the appropriate key.

Hashing:
Maps input data to a fixed-length digest.

Digital signature:
A value generated with a private key and checked with the public key.

Key exchange:
A process through which parties establish a shared secret.

Confidentiality:
Only authorized parties can read the information.

Integrity:
Unauthorized changes to data can be detected.

Authentication:
Verifies the identity or origin of a communication.

Non-repudiation:
Provides evidence of origin or signing, subject to secure key control and identity binding.

Plaintext:
Original readable information.

Ciphertext:
Encrypted information.

Nonce:
A value used once with a cryptographic key.

Salt:
Random data added to a password before password hashing.

Padding:
Extra structured data added to fit or secure a cryptographic operation.

Modulus:
The number by which a value is reduced in modular arithmetic.

Digest:
The output of a hash function.
