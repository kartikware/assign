ASSIGNMENT 6 - SHA-1 MESSAGE DIGEST AND INTEGRITY CHECK
============================================================

1. AIM
------
To calculate SHA-1 message digests for two messages, compare the digests and demonstrate
a basic file-integrity check.

2. DEFINITIONS
--------------
Hash function:
A function that maps input data of arbitrary length to a fixed-length output.

Cryptographic hash:
A hash function designed to provide properties such as preimage resistance and collision
resistance.

SHA-1:
Secure Hash Algorithm 1. It produces a 160-bit digest.

Message digest:
The fixed-length output produced by a hash function.

Integrity:
The property that data has not been altered.

Collision:
Two different inputs that produce the same hash output.

3. MATHEMATICAL FORMULA
-----------------------
The program calculates:

    digest = SHA1(message)

SHA-1 output size:

    160 bits

Since one hexadecimal character represents 4 bits:

    160 / 4 = 40 hexadecimal characters

The program compares:

    if digest1 == digest2:
        hashes are equal
    else:
        hashes are different

For an integrity check:

    original_digest = SHA1(original_data)
    downloaded_digest = SHA1(downloaded_data)

If both values match, the data is consistent with the reference digest.

IMPORTANT:
SHA-1 is considered cryptographically broken for collision resistance and should not be
used for modern security-sensitive integrity applications. Prefer SHA-256 or stronger.

4. CODE EXPLANATION
-------------------

import hashlib

def calculate_sha1(text):
Defines a function that accepts text.

text.encode('utf-8')
Converts the text into UTF-8 bytes because hash functions process bytes.

.hexdigest()

Stores the original message.

message2 = "Hello world1"
Stores a different message.

digest1 = calculate_sha1(message1)
Calculates the first digest.

digest2 = calculate_sha1(message2)
Calculates the second digest.

if digest1 == digest2:
Compares the two digest strings.

else:
Runs if the digests do not match.

original_digest = calculate_sha1(message1)
Calculates the reference digest.

downloaded_digest = calculate_sha1(message1)
In the supplied program, this line also hashes message1. It does not read a separate
downloaded file.

Therefore the file-integrity demonstration always compares the same input with itself
and should succeed. A real file check would read the downloaded file separately.

6. VIVA QUESTIONS
-----------------
Q: What is hashing?
A: Converting data of arbitrary length into a fixed-length digest.

Q: What is SHA-1 output size?
A: 160 bits or 20 bytes.

Q: How many hexadecimal characters does SHA-1 produce?
A: 40 characters.

Q: Is hashing reversible?
A: No. A cryptographic hash is designed not to be reversed.

Q: What is a hash collision?
A: Two different inputs producing the same digest.

Q: What is avalanche effect?
A: A small input change causes a large change in the digest.

Q: Why compare hashes?
A: To detect whether data differs from a trusted reference.

Q: Is SHA-1 recommended today?
A: No. Use SHA-256 or stronger for modern security-sensitive applications.

COMMON CRYPTOGRAPHY DEFINITIONS
============================================================

Symmetric cryptography:
Uses the same secret key for encryption and decryption.

Asymmetric cryptography:
Uses a related public key and private key.

Encryption:
Transforms readable data into ciphertext using an algorithm and key.

Decryption:
Recovers plaintext from ciphertext using the appropriate key.

Hashing:
Maps input data to a fixed-length digest.

Digital signature:
A value generated with a private key and checked with the public key.

Key exchange:
A process through which parties establish a shared secret.

Confidentiality:
Only authorized parties can read the information.

Integrity:
Unauthorized changes to data can be detected.

Authentication:
Verifies the identity or origin of a communication.

Non-repudiation:
Provides evidence of origin or signing, subject to secure key control and identity binding.

Plaintext:
Original readable information.

Ciphertext:
Encrypted information.

Nonce:
A value used once with a cryptographic key.

Salt:
Random data added to a password before password hashing.

Padding:
Extra structured data added to fit or secure a cryptographic operation.

Modulus:
The number by which a value is reduced in modular arithmetic.

Digest:
The output of a hash function.
